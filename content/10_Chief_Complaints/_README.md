# Chief Complaints

主訴速查頁放在這裡。請從 `Templates/Chief Complaint Template.md` 複製格式建立新頁。

## Content priority

1. `LOCAL-01`（第一次守內急就上手）是臨床工作骨架，相關內容不得刪減。
2. 每頁最前面必須有 `快速處理（先看這裡）`，讓臨床上能依序執行。
3. Harrison、On Call、Pocket Medicine 與現行指引用來補充、修正與加上安全限制。
4. 舊藥名、商品名、劑量及過時規則保留在 `LOCAL-01 藍本要點` 的警示框，不直接放進快速處理流程。

## Naming

- 使用英文主訴名稱作為檔名，例如 `Chest pain.md`、`Dyspnea.md`。
- 頁面內容使用繁中為主，臨床專有名詞保留英文或縮寫。
