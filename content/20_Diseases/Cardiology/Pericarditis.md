# Pericarditis

> [!warning] 使用範圍
> Pleuritic／positional chest pain 仍須先排 ACS、PE、acute aortic syndrome 與 pneumothorax；drug dose、renal adjustment 與 contraindication 依院內 protocol。

## 快速處理（先看這裡）

1. 先看 tamponade／shock：BP、JVP、pulsus、mental status、perfusion；不穩定立即 bedside echo 與緊急會診。
2. ECG、troponin、CBC、Cr、CRP／ESR；CXR、TTE，依情境進階 CT／CMR。
3. 急性 pericarditis 診斷整合 characteristic pain、rub、ECG change、new／worsening effusion；不要只靠單一 ST elevation。
4. 找 high-risk／specific cause：fever、subacute course、large effusion、tamponade、immunosuppression、trauma、anticoagulation、TB／malignancy／uremia。
5. Low-risk idiopathic／viral pattern 可依 protocol 使用 anti-inflammatory therapy + colchicine；限制活動並安排追蹤。

## 一句話定位

Pericarditis 是心包發炎 syndrome，重點是與 ACS 等致命胸痛區分、辨識 myopericardial involvement、effusion／tamponade 與特定病因。

## Immediate threats / red flags

- Hypotension、tachycardia、JVP elevation、pulsus paradoxus、altered perfusion。
- Large／rapidly accumulating effusion、RV diastolic collapse 或 marked respiratory variation。
- Troponin elevation 合併 LV dysfunction／ventricular arrhythmia：考慮 myocarditis／myopericarditis。
- Fever、purulent／TB risk、malignancy、immunosuppression、recent procedure／trauma。

## Focused findings

- Pain：pleuritic、positional、坐起前傾改善，可放射至 trapezius ridge。
- Rub：可短暫出現，未聽到不能排除。
- ECG：diffuse concave ST elevation／PR depression 可見，但不是人人都有；regional change 或 reciprocal pattern 要重想 MI。
- TTE：effusion、tamponade physiology、ventricular function；正常 echo 不排除 isolated pericarditis。

## Management framework

| Situation | Direction |
|---|---|
| Uncomplicated／low risk | anti-inflammatory agent + colchicine、activity restriction、CRP／symptom follow-up |
| Post-MI | anti-inflammatory choice 應考慮 post-MI safety，勿照一般 NSAID 流程 |
| Tamponade／purulent／malignant suspicion | urgent drainage／sampling + cause-specific treatment |
| Recurrent／refractory | 先確認 adherence、dose／duration、specific cause；專科評估 steroid／IL-1 strategy |

## Common pitfalls

- 看到 diffuse ST elevation 就忽略 STEMI mimic assessment。
- 以正常 echo 排除 pericarditis。
- 未評估 renal function、GI bleeding、drug interaction 就固定開 NSAID／colchicine。
- Steroid 過早使用或減量太快，增加 recurrence risk。
