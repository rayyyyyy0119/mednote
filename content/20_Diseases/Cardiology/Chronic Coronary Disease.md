# Chronic Coronary Disease

> [!warning] 使用範圍
> 新發、crescendo 或 rest symptoms 應先按 [[Acute Coronary Syndrome]] 評估；本頁不適用於正在進行的 ACS。

## 快速處理（先看這裡）

1. 先確認症狀是否真的穩定；任何 rest pain、快速惡化、syncope、HF 或 dynamic ECG change 改走 acute pathway。
2. 建立 symptom burden、functional capacity、ASCVD risk、既往 anatomy／PCI／CABG 與 medication adherence。
3. 依 pretest likelihood 與已知 CAD 狀態選擇 testing；不要同時無目的堆疊多種檢查。
4. 同步做 secondary prevention 與 antianginal therapy；治療目標是降低事件並改善生活品質。
5. 症狀 refractory、high-risk anatomy／ischemia 或 LV dysfunction 時轉 cardiology／Heart Team 評估 revascularization。

## 一句話定位

Chronic coronary disease 是穩定期 coronary atherosclerotic disease 的長期管理框架，包含症狀控制、事件預防、功能評估與適時血運重建。

## Focused assessment

- Angina pattern：exertional pressure／tightness、duration、threshold、relief、anginal equivalents。
- 判斷變化：頻率增加、活動閾值下降、rest symptoms、new HF／arrhythmia。
- Risk／comorbidity：smoking、HTN、DM、CKD、lipid、PAD／CVA、bleeding risk。
- Baseline：ECG、CBC／Cr／electrolytes／glucose、lipid；TTE 若 HF、murmur、prior MI 或 ventricular function 不明。
- Testing 依臨床問題選擇 exercise ECG、stress imaging、CCTA 或 invasive angiography。

## Management framework

| Goal | Practical approach |
|---|---|
| Event prevention | antiplatelet strategy、lipid lowering、BP／DM control、smoking cessation、physical activity、vaccination 依個人風險與禁忌 |
| Symptom relief | beta-blocker、CCB、long-acting nitrate 或其他 antianginal 依 HR、BP、LVEF、comorbidity 選擇 |
| Revascularization | 不是所有穩定 CAD 都因 PCI 延長壽命；依 symptoms、anatomy、ischemic burden、LV function、DM 與 patient preference 決策 |
| Follow-up | symptom trajectory、adherence、side effects、BP／HR、lipid response、functional status |

## Common pitfalls

- 把「穩定」當成永遠低風險，忽略症狀 pattern 改變。
- 看到 coronary stenosis 就忽略 symptom／ischemia／anatomy 與 shared decision-making。
- 同時開多種降 HR／BP 藥而沒有追蹤 bradycardia、hypotension。
- 將 aspirin、DAPT 或 low-dose anticoagulant 當成所有人固定組合，忽略出血風險與適應症。
